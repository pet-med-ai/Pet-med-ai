## 已保存结果的比较规则

GET `/api/cases/{case_id}/lab-range-review` 只读当前登录账号所属、未软删除的一个病例；不按宠物名或跨就诊拼接。只纳入当前有效、已逐项及整份核对的 CW-B7 人工报告，保持报告、项目及原文顺序；旧版本、撤销、待核对和来源失效记录单独列出且不重复计入当前数量。

使用 CW-B10 的来源字节校验、版本链和保存结构校验，在同一个 Store 锁与病例事务中完成组装。SQLite 使用现有 BEGIN IMMEDIATE，PostgreSQL 使用病例 FOR UPDATE。GET 无业务提交、清理、审计写入或原件修改。返回版本化 schema/rules、病例身份、读取时间、快照、报告版本及 token、核对者/时间、原文件名和完整 SHA256、项目位置、原始数值/单位/参考范围/标记；没有时间不补日期。响应 `Cache-Control: private, no-store`，`read_only=true`、`writes_database=false`、`includes_unsaved_drafts=false`。

- 仅 number 且保存的上下限完整、单位非空且逐字相同时，使用 Python Decimal 比较。小于/大于/严格介于范围之间分别显示；等于任一边界另列“请核对边界含义”，上下限相等亦如此。
- 单边界和仅自由文本范围不推断完整区间；比较符结果保留符号和原值，不拿阈值当实际测量值。text、not_tested、not_provided 分别展示，空值不作零值。
- 保留科学记数、负值、零、尾随零及长文本，不使用 float、单位换算、项目自动配对或从参考原文提取数值。
- 仅逐字 `H` / `L` 判断一致性：H 对应 above，L 对应 below；其他明确数值位置为冲突；边界/无法比较不判断。其他标记仅原样显示，空白不等于正常。
- 保存结构损坏、非法数字/单位、归属冲突或版本链异常返回 409；合法但资料不足返回对应项目的“无法比较”。401、404、409 和 503 保持区别；无失败缓存替代。

位于上下限之间、没有区间外项目或“已核对”均不表示健康、诊断或排除疾病。此处不产生医疗阈值、自动诊断或文书内容。

## 界面与旧流程

病例详情以显式按钮懒加载新面板，默认列出全部当前报告，筛选区间外/无法比较并显示准确数量。按 case/token/请求轮次与 AbortController 丢弃迟到响应；焦点返回、主动刷新、sourceRevision 变化及原件/检验 confirm 开始立即清除旧快照，成功或失败后重新读取，即使编辑器后续 GET 失败未调用 onChanged 也刷新。
