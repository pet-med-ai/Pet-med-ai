# CW-B5 外部语音病史草稿

批准：2026-10-06 16:57（北京时间）。承接草稿 PR #49，固定基线 `8109a629b6b7159873ff6723c7833a1b26656117`，树 `11c5a93face82e578caddba398160d15d1736add`。异宠目录原有 B5＝Snake Depth V2 不改；CW-B5 只是伴侣动物医生工作流的对应编号。

## 行为

登录医生建立问诊后，可在问诊整理页打开语音草稿，补充首次保存病史或已保存病例的病史补记。每段 0.1–30 秒，WAV 16 kHz、16 bit、单声道，最大 2 MiB。录音不会持续监听，必须主动提交。未启用时仍可手工输入。

原始转写、医生修订与药名、数字、小数点、单位、频率和否定词提醒并列。医生核对后按段追加，随后经过既有保存预览、确认与回读。转写不自动正式入库，不做诊断、处方或大模型润色；不启用真实 R1。

来源绑定账号、问诊、病例、动物、物种、服务端版本及本页草稿版本。手工修改或恢复后必须重新核对；重新核对文字不再次发送音频。来源不能改绑另一只动物或问诊。迟到响应、取消及离开页面不把结果写入新上下文。首次保存和补记的来源审计与病例事务一同提交，重复请求不重复追加。

只有医生确认加入病史的文字与来源进入本标签页恢复缓存，恢复不保留任何审批状态。服务端只在最终病例保存时审计原始转写、修订文字、确认医生和 UTC 时间。两类 DOCX 仍读取最终病史，病史改变后旧文书确认失效。

## 外部数据和留存

唯一供应商：腾讯云中国站 SentenceRecognition，API `2019-06-14`、通用引擎 `16k_zh`。HTTPS 正文传入音频，不创建公开音频 URL。TC3 签名、密钥与可选临时令牌仅在后端；不启用过滤语气词、强制热词替换和自动数字改写。未假定通用模型具有兽医专用准确率。

浏览器录音仅内存保留，取消、提交结束/失败、上下文变化、pagehide 或组件卸载释放；未提交录音最多 10 分钟，请求最长等待 60 秒。后端流式读取限制正文大小，避免 UploadFile 临时落盘；外部调用总超时 45 秒。不落音频到数据库、应用日志或证据。内存释放指移除引用及停止录音，不承诺运行时内存安全擦除。

供应商[通用 FAQ](https://cloud.tencent.com.cn/document/product/1093/35802)说明传入音频不保存、识别文字在服务器保留 7 天，本批按可能保留文字 7 天处理；训练用途、备份日志及账户专属删除条款仍需正式临床启用前核实。仅授权虚构病例合成音频，不发送真实门诊录音。

## 费用和幂等

本批固定最多 100 次、人民币 1 元。每次出网前按 1 分钱持久化占额，失败/超时/结果未知也不退回；无自动重试。同一请求 ID 只能占一次额，状态查询不返回未确认原文，不再次出网。公布价格为 3.20 元/千次，100 次约 0.32 元，不依赖免费额度。价格升高必须停止重新核定。

账本复用 AuditLog，仅追加记录。固定批次锚点校验完整政策；SQLite `BEGIN IMMEDIATE` 与 PostgreSQL 锚点行锁串行化预留，校验连续序号、占额和请求主键。请求、结果及确认分别使用确定性主键。服务启动不会初始化、清空或重置账本。缺失、异常或写入失败时拒绝发送。数据库管理员恶意删除账本尾部或恢复旧备份不能仅凭同一数据库检测；禁止这样恢复额度，需保留隔离测试数据库及其预算记录。

## 开发配置与实测入口

默认关闭；仅 `ENVIRONMENT=test/development` 且 `RENDER` 非 true 的隔离开发后端可启用。需要 `SPEECH_ENABLED=1`、`SPEECH_SYNTHETIC_ONLY=1`、`SPEECH_REVIEWED_CNY_PER_1000=3.20`，以及受保护的 `TENCENTCLOUD_SECRET_ID`、`TENCENTCLOUD_SECRET_KEY`、可选 `TENCENTCLOUD_TOKEN` 和有效 `SECRET_KEY`。不能把凭据写进仓库、聊天、前端或 CI；本批不修改生产配置。

`scripts/verify_voice_provider_cw_b5.py` 仅允许已建好的本地 `cwb5` 合成数据库，独立 `--synthetic-only --initialize-ledger` 命令一次初始化固定账本，不创建表或迁移。随后传入 `--synthetic-only --audio-dir <合成音频目录> --output <新证据文件>` 执行固定 20 条台词；需要预先离线生成对应 `cwb5-01.wav` 至 `cwb5-20.wav`，轻噪声条件见 JSON 清单。固定请求 ID 避免脚本重复外发，首个错误即停止；不自动充值、买包或重试。参考文字、返回文字、耗时及缺词提示不等于医学准确率，错误需逐条人工归类。

当前环境没有测试凭据，网络许可未包含腾讯 ASR；真实 ASR 实测待补，实际外部调用 0 次、费用 0 元。代码和 CI 使用模拟供应商；测试拦截外网，不能把模拟结果记作真实识别验收。
