## 医生操作

1. 在“检查资料”明确关联并确认 DR 或超声 PDF/JPEG/PNG 原件。
2. 打开“影像记录”，选择原件，填写标题、检查类型、部位、明确检查时间及其时区、机构、所见原文、结论原文、局限性、备注和原件位置。日期不默认当前时间；所见和结论至少有一项，缺失的其他原文保持空白。
3. 对照原件分别核对所见和结论，再预览完整记录，核对病例身份、来源完整 SHA-256、版本和内容后确认保存。
4. 更正和撤销须说明原因；更正生成新版本，旧版保留。断线只查询保存结果，禁止自动重复 POST。未知结果期间锁定编辑。
5. 在两类草稿中明确勾选整份影像报告，可同时选择检验报告。重新读取并核对完整文书后下载；文件仍为未签署草稿。

每病例最多 20 份有效影像记录、每记录最多 20 个版本；同一原件只建一个记录根。所见/结论各最多 5000 Unicode 字符，局限性/备注各 1000。标题/机构各 150、部位 100、检查时间 40、原件位置 255、更正/撤销原因 500。超限拒绝，不截断原文。

文书最多选择 5 份影像报告，所见、结论、局限性与备注合计 20000 Unicode 字符；检验仍沿用最多 5 份、200 项。默认不选择，原文书保持原行为。原文中的换行、制表符、比较符、特殊字符和 `{{...}}` 保留为字面文本。

## 事务、来源及历史隔离

复用 `ImagingStudy`、`Case.attachments`、`AuditLog`；不新增表、迁移、依赖、锁文件或模板二进制。`taken_at` 从显式时间转换为 UTC 存现有字段，原始时区字符串完整保留。人工来源为 `manual-imaging-cw-b9`；旧列表、旧复核写入口、诊断汇总、自动文书合入及影像 KPI 均排除这一来源，避免更正版本被当成新检查或旧流程绕过核对。

保存审计与记录在同一事务，幂等请求回读当前状态。原件更正、撤销和病例身份变更在原事务中使记录失效；原件丢失/损坏即时拒绝作为当前记录。即使关闭人工影像功能，测试环境的身份/来源修改仍使已有记录失效。

混合文书只获取一次原件 Store 锁和一次病例行事务，同时读取检验与影像，持续持锁直到 DOCX 字节生成。快照绑定病例文书字段、模板原件、所选记录、版本、来源和核对信息。任一选择、来源、记录、身份或病例文书字段变化都使旧确认失效；不混合不同事务的版本。预览和导出均无持久写入。

浏览器草稿仅在内存；切换病例/账号/模板、来源变动、刷新或失焦后重新获得焦点清除旧文书确认。迟到响应不能跨病例/账号显示或触发下载。已下载文件不会随之后更正自动改变，需重新核对导出。
