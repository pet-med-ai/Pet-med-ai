## 行为

门诊病历 `outpatient_record_zh` 默认不选择复查计划。医生明确选择已保存的当前有效版本，重新读取完整文书并另行核对，再下载尚未签署的 DOCX。未选择时提示“本次文书未纳入复查计划，请医生确认复查安排”，不推断是否已有计划或是否需要复查。其他三种模板拒绝本批选择参数。

`manual_followup_plan` 只接受 `{id, version, token}`，严格校验正整数、完整内容标识及字段集合。服务器读取 CW-B14 版本链、原文字段、上海日期、确认账号与时间；旧版本、撤销、病例已变更和损坏记录不能进入文书。文书附节保留原文、项目顺序、根记录与版本，不生成临床建议，也不登记实际复查完成、预约或发送消息。

计划单独导出复用 CW-B14 病例事务；混合检验、影像、对照复用各自原件锁和同一会话，无嵌套病例事务。完整快照包含模板字节、病例、账号、计划及所有选定附节。导出在同一事务内重核快照并生成全部 DOCX 字节，再释放锁。预览及导出不写业务表或原件。成功和本批服务错误为 private/no-store。

前端默认不选，取消、刷新、焦点、账号/病例/模板变化、正文或相关保存请求启动均使本次旧核对失效；成功或失败后独立回读。收起选择面板仍保持保护。过期预览与下载不恢复确认，重复点击只能发起一次有效下载。回看定位到准确记录与版本，保留未保存的检验、影像和复查草稿。复查附节实际显示完成后才能勾选全文核对。

`FOLLOWUP_PLAN_DOCUMENTS_ENABLED` 与 `FOLLOWUP_PLAN_DOCUMENTS_SYNTHETIC_ONLY` 默认关闭，另需 CW-B14 开关；只允许 test/development、非 Render 合成环境。未选择计划无需读取计划表，也无需开启本批功能。无依赖、锁文件、模型、迁移、模板二进制、主路由或基础设施变更。
