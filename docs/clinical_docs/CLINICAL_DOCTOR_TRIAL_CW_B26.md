本批在 CW-B25 草稿 PR #70（`3063eb61ac722bfa8900246ea8a7833c57beaaa6`）之上提供本机练习入口。
只用合成犬猫和本次新建的临时 SQLite；不接入已有数据库，不运行迁移，不调用外部业务接口。它用于操作候选软件，不能存放真实患者信息。普通构建默认关闭此入口。

## 准备一次，然后每次一条命令启动

依赖已准备好的电脑，在候选仓库根目录运行：

```bash
python3 scripts/run_clinical_doctor_trial_cw_b26.py
```

若使用项目虚拟环境，将 `python3` 换成 `.venv/bin/python`。默认浏览器地址为 `http://127.0.0.1:5174`，后端为 `http://127.0.0.1:18027`。
终端出现 `PMAI_TRIAL_READY` 后，用其中的本次邮箱和密码登录。这些账号只在本轮练习有效，不是医院账号。
页面顶部持续显示“合成病例练习，不录入真实资料”；展开“练习步骤与犬猫样例”即可查看固定入口、操作步骤和合成原件下载。

macOS 若尚未准备依赖，需要本机已有 Git、Python 3.11+、Node 20+；在候选源码目录先执行以下准备命令。此准备需要下载项目声明的依赖；启动器本身不安装、不升级、不拉取源码。

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt -r backend/requirements.txt
npm ci --prefix frontend
.venv/bin/python scripts/run_clinical_doctor_trial_cw_b26.py
```

可选：用 `--expect-head` 绑定最终 PR 回执的完整 HEAD；用 `--receipt` 指定一个尚不存在的 JSON 文件保存脱敏启动回执。
回执记录 Git HEAD、源码 SHA256、工作区是否干净、会话、运行平台和退出清理结果，不写入密码、JWT 或签名密钥。
工作区有改动时会如实标记 `clean:false`，源码指纹绑定实际文件，不把它冒充已通过 CI 的精确候选。构建期间源码变化则拒绝启动。

```bash
.venv/bin/python scripts/run_clinical_doctor_trial_cw_b26.py --expect-head <最终PR的完整HEAD> --receipt ~/Desktop/cwb26-session-1.json
```

## 练习一次完整就诊

1. 使用合成犬或合成猫，或从“手工新建合成病例”入口练习建档。
2. 下载样例 PNG/PDF，再在“检查资料”中上传、核对和关联。样例不是有临床意义的影像。
3. “操作样例 JSON”给出原有 CW-B24 固定合成文字。手工录入检验、影像，将检验结果 `0.0100` 更正为 `0.0300`，确认原版保留。
4. 保存复查计划和人工随访，从复查工作清单回看对应版本。
5. 核对门诊病历及宠主说明草稿，主动下载 DOCX；刷新、退出后用本次账号重新登录，核对原文仍在。
6. 将发现的问题记为：候选 HEAD／操作步骤／预期／实际／截图。只记录合成数据，不附账号密码或 token。

沿用 [CW-B24 医生检查清单](CLINICAL_VISIT_JOURNEY_CW_B24.md)。原有人工验收按原凭证、原版本保留，不重复要求已完成的同项验收。
Linux Chromium 自动通过不代表医生体验认可，也不代表已在用户的 Mac 上启动；macOS 实测按真实操作另记，不代填通过。

## 退出、失败与重新启动

在启动终端按 Ctrl+C，关闭的仅是本次创建的服务。临时数据库、私有附件、构建文件和临时账号一起清理。主动下载到“下载”目录或自行保存的问题记录保留。
再次启动会得到新会话、账号、签名密钥及固定初始样例，上一轮 token 失效。普通退出和 SIGTERM 均测试清理；断电或强制 SIGKILL 无法执行清理代码，不声称这种情况下已删除临时目录。下次启动仍新建独立目录，不扫描、复用或删除旧目录。

缺依赖、端口占用、候选不符、目录标记错误或非空数据库都会拒绝启动，不杀占用端口的其他进程。可用 `--ui-port` / `--api-port` 指定两个空闲的高位端口，监听地址始终为 `127.0.0.1`。
前端首次进入、窗口回到前台、定期检查及每次业务请求前，都核对会话和候选身份；失败后停止页面操作，不自动重发保存。从普通后端返回的结果不会当作练习结果。重新启动后刷新页面、使用新账号，不沿用旧页继续编辑。

启动器清除继承的数据库、密钥、代理、功能开关及 Node/Python 注入变量，不读取项目 `.env`。后端审计钩子拒绝所有出站连接及外部 DNS，只可打开本轮 SQLite；临床界面调用仅限本轮练习接口，真实 AI、语音、EMR、设备、通知、账单接口不启用。
手机远程访问、云部署、公开预览、Docker 和安装器不在范围。
