## 医生操作

已保存病例详情按需打开“检查资料”，选择 PDF/JPG/JPEG/PNG 原件并暂存。填写标题、资料类型（检验/DR/超声/其他）、检查或采样时间、报告时间、来源和备注；未记录保持空白。核对病例、原件和资料信息后勾选并确认关联。更正信息和有理由的撤销必须重新核对。原件不可覆盖，撤销后列表保留状态和原因，阻止原件下载；无硬删除、跨病例移动或外部 URL 抓取。

标题、类型筛选；图片通过认证接口获取、前端 SHA-256 校验后在临时 Blob URL 预览。PDF 只授权下载，不在页面内嵌解析。关闭图片、切换病例或账号时释放预览；迟到响应不能进入新病例。新增模块动态加载，保留初始 JS 460000 字节门禁；原门诊/宠主文书及病史、诊断正文不注入附件内容。

## 存储与数据一致性

默认关闭。仅 `ENVIRONMENT=test/development`、`RENDER=false`、`CASE_ATTACHMENTS_ENABLED=1`、`CASE_ATTACHMENTS_SYNTHETIC_ONLY=1` 且配置私有绝对目录 `CASE_ATTACHMENTS_DIR` 时启用；Render/生产拒绝。测试均由隔离 fixture 设置，不提供生产启用操作。目录必须在仓库及静态发布范围外、由运行账号持有，不允许符号链接；权限 0700，原件/暂存 0600，无公开挂载。隔离测试目录不是上线后的永久存储方案。

单文件 10 MiB；单病例最多 20 个有效原件/100 MiB；整个私有目录最多 500 MiB，包含暂存、清单、已撤销原件。验证扩展名、声明 MIME、文件特征和基本结构，拒绝空文件、超限、明显截断和路径文件名。此识别不代表恶意文件查杀、完整 PDF 语义审查或真实影像质量校验；真实资料启用前须另行确定持久存储、运维、保留规则和内容防护。

存储键由账号、病例和请求号生成，原始文件名不作磁盘路径。原件以临时文件写入、fsync 后原子更名，再提交上传审计；DB 未提交时原件仅作暂存，不可通过病例下载。暂存 1 小时到期，列表/上传时清理无已提交引用的过期原件、清单及残留临时文件。取消可清除未确认原件。保护全部病例引用，包含已删除病例和已撤销资料；本批保留已确认原件，不提供永久删除策略。

复用 `Case.attachments` JSON，schema=`case-attachment-cw-b6-v1`；保留未知历史条目，不读取历史 URL。记录原件名、MIME、大小、SHA-256、上传人/时间、确认人/时间及修订/撤销信息。`AuditLog` 记录上传、确认、更正、撤销、预览和下载；不写文件正文、令牌或私有绝对路径。未确认上传/取消使用独立暂存清单状态；确认、更正、撤销与对应审计在同一 DB 事务中提交。

进程间文件锁协调同一私有目录的容量和清理；SQLite `BEGIN IMMEDIATE` / PostgreSQL 病例行锁及病例版本标识协调关联变更。请求号绑定账号、病例、原件、操作和内容。核对令牌绑定所见版本；病例/附件变化后旧核对失效。相同内容、相同请求重放回读现态；改变载荷拒绝。相同有效原件 SHA-256 去重，不覆盖旧信息。

上传/确认丢失回包先 GET 请求状态；不自动重复 POST。服务重启后从 DB 审计及私有清单重建结果。数据库失败回滚关联和审计；暂存可按原请求恢复或到期清理。文件损坏、丢失、容量不足或 DB 不可用时关闭该操作，不回退成公开链接，也不改变原病史。

每次列表、暂存、确认、撤销、回读、预览和下载均重新核验账号/病例归属、病例未删除及当前状态。下载仅在有效关联下返回，经原件哈希校验，设置 private/no-store、nosniff；PDF 下载使用 attachment disposition。权限范围与现有单账号病例规则一致，本批不增加院内共享授权。
