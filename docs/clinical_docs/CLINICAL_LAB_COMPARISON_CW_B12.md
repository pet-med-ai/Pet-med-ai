## 已保存记录和可比条件

只对当前账号所属、同一个未删除 Case 内当前有效且医生已逐项与整份核对的 CW-B7 报告提供选择。当前 Case 无稳定跨就诊患者关联，不按动物名或主人电话拼接病例。A、B 报告与两个项目均默认不选，禁止自动匹配或默认最新两份。

服务器从保存资料读取数值，客户端只发送快照和准确报告 ID/版本/token/项目索引/原文位置，以及临时确认。两侧必须来自不同根记录、不同 SHA256 原件，项目名称与非空单位逐字相同，均为 number；panel/specimen/laboratory/device 非空且逐字相同，带时区采样时间转换 UTC 后 A 严格早于 B。缺项和不一致只显示原因；比较符、文本、未检测、未提供不当零或实际测量值；报告时间不替代采样时间。

实验室和设备相同不证明方法相同。医生需对照原件明确勾选项目、方法和采样条件可比，才返回差值。该勾选不持久化，不改变报告核对状态，也不是医生验收；选择、交换、刷新或快照失效立即清除。

Python Decimal 精确计算 B−A，按对齐指数后的整数系数位数加进位空间确定上下文精度，开启 Inexact/Rounded 陷阱；不使用 float 或默认 28 位精度。输出仅为数值增加、减少或相同。原值、尾随零、科学记数、单位、参考范围和标记完整保留。各自参考范围不同则明确提示，仍只做满足其他条件的同单位相减；不作病情、诊断、正常或异常变化判断，没有百分比、变化率、多点曲线、插值、平均、单位换算或临床阈值。

## 只读快照和失效

GET `/api/cases/{case_id}/lab-comparison` 与 POST `/api/cases/{case_id}/lab-comparison/preview` 均只读，在 Store 锁和病例事务中复用 CW-B11 保存结构、版本链及原件校验。SQLite BEGIN IMMEDIATE、PostgreSQL Case FOR UPDATE 保持一致快照。无业务提交、审计、清理、确认账本或原件修改。接口带版本化 schema/rules、读取时间、快照和只读标志，响应 private/no-store。

未登录 401，无权/不存在/已删除 404，旧快照或选择、损坏结构和异常版本链 409，非法请求 422，关闭开关或读取故障 503。来源失效报告单列并排除；旧选择预览拒绝。合法不可比条件返回原因及空差值。不能用缓存或另一保存版本替代。

功能默认关闭，须 `LAB_COMPARISON_ENABLED=1`、`LAB_COMPARISON_SYNTHETIC_ONLY=1` 及既有原件/人工检验开关，限定 test/development 且非 Render。无需开启 CW-B11 展示开关。无新表、迁移、依赖、锁文件、模板或基础设施，无 OCR、设备或模型调用。
