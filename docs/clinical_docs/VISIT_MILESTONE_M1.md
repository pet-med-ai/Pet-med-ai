## 验收标准

1. 既有 140 项前端回归与新增 15 项详情/文书回归通过。
2. 新增 3 项真实 ASGI/认证/隔离 SQLite 文书测试通过：两模板内容与已保存病例对应且无数据变更；软删除后两个接口均拒绝；匿名/其他账号拒绝。
3. 保留既有 PostgreSQL/Chromium 验收，新增长链：手工核对创建→实际回读→核对更正→回看→下载两模板→解包核对更正内容；导出不引起病例写入；离页不下载旧文书；删除后导出拒绝。
4. main 内容、候选文件集合/哈希、实际提交 CI 精确对应；双端 Auto-Deploy / PR previews 在提交前均 Off。
5. 本地构建成功；不将隔离 API 构建产物发布到生产。
