activation contract for a future Active Restore Runner V3. It consumes only
published repository evidence for the authorized inert implementation and the
available fresh disposable target. It does not create or activate an active
runner, access the backup, retrieve a credential, connect to the target,
restore, create or execute migration 0010, deploy, delete, stage, commit, or
push.
